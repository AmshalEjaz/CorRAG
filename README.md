### Key Interface Features:
* **Document Ingestion:** Easy PDF or TXT file upload and automatic vector indexing.
* **Self-Correcting QA:** Evaluates document context before generating precise, citation-backed answers.
* **Database & Memory Controls:** Instant vector database reset and option to enable web search fallbacks when local documents lack relevant information.
